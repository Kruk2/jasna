# 保持输入子文件夹结构与批量恢复

GUI 勾选保持输入目录的子文件夹结构后，按照每个任务的输入根目录计算输出
相对路径，并在发布前建立所需目录。Full、Smart Render、源流复制及恢复任务
共用输出路径规则，Linux 与 Windows 共用实现。

路径必须留在用户选择的输出根目录内；不能因绝对路径、父目录逃逸、符号链接
或名称碰撞覆盖其他位置。批量恢复验证已有成片的媒体合同，文件仅存在不等于
已成功完成。失败和取消保留诊断/断点，未完成任务不显示为成功。

路径与恢复验证组件在本功能 PR；Processor、队列模型和 GUI 设置的调用点在
相应集成 PR。测试使用临时目录和假媒体信息；本次重建不启动用户真实视频。

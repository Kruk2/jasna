# 只修复视频的一部分

你不必修复整个视频。只选有马赛克的场景即可。Jasna 会原样复制其余部分，
所以快得多，其他部分也保持原始质量。输出仍然是完整的视频。

## 区间编辑器（GUI）

<img width="822" alt="Segment editor" src="https://github.com/user-attachments/assets/c67939a9-37de-46ae-b722-20c6a0933df7" />

点击队列中视频上的剪刀按钮即可打开。

- 选择要修复的区间，可精确到帧。不选任何区间时，会修复整个视频。
- **修复方式**为每个区间设置模型：BasicVSR++ 或
  [LTX](models.md#修复模型)。
- **修复预览**在开始任务前显示修复后的画面。
  - BasicVSR++ 区间会立即显示。
  - LTX 区间需要先渲染。点击**渲染 LTX 种子 N**；按钮会显示需要多长时间
    （通常几分钟）。较长的渲染开始前，Jasna 会先询问。
  - 比较 LTX 种子：选择另一个种子再渲染一次。试过的种子列在**已试**下面。
    点击一个即可查看，再点**使用这个种子**保留它。
- 用 **− / +** 或鼠标滚轮缩放，拖动画面可移动。**重置视图**可恢复原样。
- 选择了区间时，输出会保留源视频的编解码器。**编码设置**中的**编解码器**设置
  不会生效，因为区间之间的部分是直接复制的。如果某个视频无法按区间处理，
  编辑器会立即告诉你。
- BasicVSR++ 区间和 LTX 区间之间需要留一些距离。离得太近时，编辑器会提示你。

### 马赛克扫描

编辑器可以帮你找出有马赛克的场景。

1. 选择检测模型和检查频率：每一帧（最准确）或每 0.25–2 秒（更快）。
   在 RTX 5090 上，扫描速度约为 **2,000 FPS**。
2. 点击**扫描视频**。找到的区间在时间线上显示为琥珀色。
3. 移动**检测阈值**滑块，可以改变哪些算作找到。
4. **添加全部 N 个区间**把琥珀色区间变成紫色区间，紫色区间会被修复。

- **在预览中显示遮罩**用红色画出找到的马赛克，并标出大小（最长边占视频高度的
  百分比）。
- 如果你的电脑能运行 LTX，扫描后会出现**仅大马赛克用 LTX**。它把有大马赛克的
  地方设为 LTX 区间，其余设为 BasicVSR++ 区间，让较慢的 LTX 只用在最有帮助的
  地方。“大”是指最长边至少达到滑块的数值（占视频高度的百分比）。建议从 12%
  开始。检查这些区间，不满意的可以修改。

检测模型和检测阈值会保存给这个视频，并用于最终任务。其他视频保留各自的设置。

### 建议更好的遮罩

如果检测结果不对，你可以帮忙训练更好的模型。暂停在该帧，点击
**建议更好的遮罩**，然后把每个马赛克圈出来。编辑器会教你怎么做。如果马赛克的
边缘柔和或模糊，也请一起圈进去。

Jasna 会**匿名**上传该帧和你的遮罩。数据在你的电脑上加密后才上传。只附带应用
版本、检测模型名称和帧大小。不包含文件名、时间，也不包含任何关于你的信息。

## CLI: `--segments`

和编辑器的功能一样，只是在命令行中使用。时间用秒数或 `HH:MM:SS.s`：

```bash
jasna --input input.mp4 --output output.mp4 --segments "10-25,01:10-01:30.5"
```

Jasna 会修复列出的区间，并复制其余部分。每个区间前后会有几秒被重新编码
（但不修复），因为视频只能在某些帧处切开。

限制：

- 支持 NVIDIA 和 AMD。
- 一次一个视频。不支持文件夹、图片或流媒体。
- 输入：恒定帧率的 H.264、HEVC 或 AV1。输出：MP4、MOV 或 MKV。
- 输出编解码器始终与输入相同。
- 在 AMD 上，部分 H.264 文件会整体重新编码。只有区间会被修复。
- 使用 `--restoration-model-name ltx` 时，所有区间都用 LTX。
- 不能与 `--retarget-high-fps` 或 `--fmp4` 一起使用。

如果输入无法使用，Jasna 会在开始前报错停止。

## CLI: `--ltx-auto-split`

和**仅大马赛克用 LTX**相同，用于命令行。Jasna 先扫描每个视频，然后用 LTX 修复
大马赛克，其余用 BasicVSR++。也可用于文件夹：

```bash
jasna --input videos/ --output restored/ --restoration-model-name ltx --ltx-auto-split 12
```

这个数字是马赛克大小，占视频高度的百分比。输出保留源视频的编解码器。如果某个
视频无法按区间处理，会整段用 LTX 修复。不能与 `--segments` 或 `--fmp4` 一起使用。

## 工作目录

Jasna 拼接视频时，会把临时文件放在输出旁边的隐藏文件夹中。要使用另一块磁盘
（更快或更大），请在**编码设置**部分设置**工作目录**，或使用：

```bash
jasna --input input.mp4 --output output.mp4 --segments "10-25" --working-directory /fast/scratch
```

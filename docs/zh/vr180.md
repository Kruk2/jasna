# VR180 视频

VR180 文件通常把左眼和右眼画面并排放在一个宽画面中。Jasna 会拆分画面，分别修复
每只眼，再把它们拼回去。

LTX 无法修复 VR180 左右并排视频。请使用 BasicVSR++。

## 快速设置

1. 像添加普通视频一样添加 VR 视频。
2. 把 **VR180 模式**保持为**自动（推荐）**。
3. 使用内置的 **rfdetr-vr-v1** 检测模型。**zelefans-vr-yolo-v2**（单独下载）
   是另一个选择。
4. 开始任务。也可以用[区间编辑器](segments.md)只修复部分内容。

自动模式会把所有高度超过 1080 像素的 2:1 视频视为左右并排 VR，例如 3840x1920
或 8192x4096。文件中的 VR 元数据和已知的 VR 片商名称也会开启 VR。

## 投影

各片商制作马赛克的方式不同，所以一个设置不能适合所有视频。Jasna 会按片商选择
修复前如何展平马赛克。画面的其余部分不会改变。

- **原始**：按原样使用马赛克。未知片商的默认值。
- **鱼眼**：用于马赛克在鱼眼视图下看起来正常的片商。
- **球心投影**：没有变形的平面视图。

对于 VR180 视频，区间编辑器会在**修复预览**旁边显示 **VR 投影**菜单。打开
**修复预览**，试试**自动**、**原始**、**鱼眼**和**球心投影**。标签会显示**自动**
选了哪个。**应用**会保存你的选择，最终任务会使用它。

## 模式

- **自动（推荐）**：Jasna 判断视频是否为 VR，并按片商选择投影。先用这个。
- **关闭**：把文件当作普通平面视频处理。
- **SBS — 分眼处理**：自动模式认不出文件时，强制按 VR 处理。投影仍按片商选择。
- **SBS + 鱼眼**：强制按 VR 处理，并对每个马赛克使用鱼眼。

CLI：
2. 将 **VR180 模式**保持为**自动（推荐）**。
3. 为了获得最佳 VR 马赛克检测效果，请使用内置的 **rfdetr-vr-v1**
   检测模型（**zelefans-vr-yolo-v2** 为可选备用）。
4. 正常开始处理。如果只想修复视频的一部分，也可以使用
   [区间编辑器](segments.md)。

自动模式始终会把高度超过 1080 像素的严格 2:1 视频视为并排 VR —
例如 3840x1920 或 8192x4096。兼容的 VR 元数据和已知 VR 片商名称也
可以启用 VR 处理。

## VR 投影选项

各片商制作马赛克的方式不同，没有适合所有视频的单一设置。Jasna 会在修复
前按片商为每个马赛克区域选择最合适的展平方式；马赛克以外的画面完全不受
影响：

- **raw** — 按画面中的原样使用该区域（未知片商时的安全默认值）；
- **鱼眼** — 适用于马赛克在鱼眼视图下显示正常的片商；
- **等距投影（gnomonic）** — 平坦、无变形的视图。

当前自动鱼眼片商为 `CCVR`、`CRVR`、`DSVR`、`FSVSS`、`KBVR`、`KMVR`、
`JPSVR`、`MAXVR`、`NHVR`、`PXVR`、`SAVR`、`TMAVR` 和 `URVRSP`。
其中新增片商按完整片商代码识别，`KMVR`、`DSVR` 不会误匹配 `BIKMVR`
或 `3DSVR`。

视频被识别为 VR180 后，区间编辑器中的 **VR 投影**菜单会启用。打开
**修复预览**，再选择**自动**、**raw**、**鱼眼**或**等距投影
（gnomonic）**，即可比较当前帧或播放画面。该控件位于**修复预览**旁边，
标签会显示**自动**模式实际使用的投影。选择**应用**后，此设置会为当前视频
保存，最终处理将使用与预览相同的投影。

## 模式说明

- **自动（推荐）**: 让 Jasna 自动判断检测与按片商的投影选择。建议先使用
  此模式。
- **关闭**: 把文件当作普通平面视频处理。
- **SBS — 分眼处理**: 如果自动模式未识别该文件，使用相同的按片商投影
  选择强制并排 VR 处理。
- **SBS + 鱼眼**: 无论片商如何，都对每个马赛克区域强制使用鱼眼投影。

CLI 对应命令:

```bash
jasna --input input.mp4 --output output.mp4 --vr-mode auto
jasna --input input.mp4 --output output.mp4 --vr-mode sbs-fisheye
```

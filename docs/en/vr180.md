# VR180 Videos

VR180 files usually contain the left-eye and right-eye pictures next to each
other in one wide frame. Jasna splits that frame, restores each eye
separately, and joins the two eyes again for the output.

## Quick setup

1. Add the VR video like any normal video.
2. Leave **VR180 Mode** set to **Auto (recommended)**.
3. For the best VR mosaic detection, use the bundled **rfdetr-vr-v1**
   detection model (**zelefans-vr-yolo-v2** is an optional alternative).
4. Start processing normally. You can also use the
   [segment editor](segments.md) if you only want to restore part of the
   video.

Auto mode always treats an exact 2:1 video taller than 1080 pixels as
side-by-side VR — for example 3840x1920 or 8192x4096. Compatible VR metadata
and known VR studio names can also enable VR processing.

## VR projection choices

Studios prepare their mosaics in different ways, so no single setting fits
every video. Jasna picks the best way to flatten each mosaic region per
studio before restoring it; everything outside the mosaic stays untouched:

- **Raw** — use the region exactly as it appears (the safe default for
  unknown studios);
- **Fisheye** — for studios whose mosaics look right in a fisheye view;
- **Gnomonic** — a flat, undistorted view.

When a video is detected as VR180, the segment editor enables a **VR
projection** menu. Turn on **Restore preview**, then choose **Auto**, **Raw**,
**Fisheye**, or **Gnomonic** to compare the current frame or playback. This
control sits beside **Restore preview**, and its label shows the projection
that **Auto** resolves to. Choosing **Apply** saves the selection for that
video, so final processing uses the same projection you previewed.

## What the modes mean

- **Auto (recommended)**: let Jasna decide detection and the per-studio
  projection choice. Start here.
- **Off**: treat the file as an ordinary flat video.
- **SBS — per eye**: force side-by-side VR processing if Auto does not
  recognize the file, using the same per-studio projection choice.
- **SBS + fisheye**: force the fisheye projection for every mosaic region,
  regardless of studio.

CLI equivalent:

```bash
jasna --input input.mp4 --output output.mp4 --vr-mode auto
jasna --input input.mp4 --output output.mp4 --vr-mode sbs-fisheye
```

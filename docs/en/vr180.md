# VR180 Videos

A VR180 file usually has the left eye and the right eye next to each other in
one wide frame. Jasna splits the frame, restores each eye on its own and puts
them back together.

LTX can't restore VR180 side-by-side videos. Use BasicVSR++.

## Quick setup

1. Add the VR video like any other video.
2. Leave **VR180 Mode** on **Auto (recommended)**.
3. Use the included **rfdetr-vr-v1** detection model. **zelefans-vr-yolo-v2**
   (separate download) is another option.
4. Start the job. You can also use the [Segment Editor](segments.md) to
   restore only some parts.

Auto treats every 2:1 video taller than 1080 pixels as side-by-side VR, for
example 3840x1920 or 8192x4096. VR metadata in the file and known VR studio
names also turn VR on.

## Projection

Studios make their mosaics in different ways, so one setting doesn't fit all
videos. For each studio Jasna picks how to flatten the mosaic before
restoring it. The rest of the picture is not changed.

- **Raw**: use the mosaic as it is. Default for unknown studios.
- **Fisheye**: for studios whose mosaics look right in a fisheye view.
- **Gnomonic**: a flat view without distortion.

For a VR180 video, the Segment Editor shows a **VR projection** menu next to
**Restore preview**. Turn on **Restore preview** and try **Auto**, **Raw**,
**Fisheye** and **Gnomonic**. The label shows what **Auto** picked. **Apply**
saves your choice, and the final job uses it.

## Modes

- **Auto (recommended)**: Jasna decides if the video is VR and picks the
  projection for the studio. Start with this.
- **Off**: treat the file as a normal flat video.
- **SBS — per eye**: force VR processing when Auto doesn't recognize the
  file. The projection is still picked per studio.
- **SBS + fisheye**: force VR and use fisheye for every mosaic.

CLI:

```bash
jasna --input input.mp4 --output output.mp4 --vr-mode auto
jasna --input input.mp4 --output output.mp4 --vr-mode sbs-fisheye
```

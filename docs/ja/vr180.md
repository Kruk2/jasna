# VR180 動画

VR180 ファイルでは通常、左目用と右目用の映像が 1 枚の横長フレームに
並んでいます。Jasna はそのフレームを分割し、左右の目を別々に復元してから、
出力時に再び結合します。

## かんたん設定

1. 通常の動画と同じように VR 動画を追加します。
2. **VR180 モード**は**自動（推奨）**のままにします。
3. VR モザイクを最も正確に検出するには、同梱の **rfdetr-vr-v1**
   検出モデルを使います（**zelefans-vr-yolo-v2** は任意の代替です）。
4. 通常どおり処理を開始します。動画の一部だけを復元したい場合は、
   [区間エディター](segments.md)も使えます。

自動モードでは、高さが 1080 ピクセルを超える正確な 2:1 動画を必ず
サイドバイサイド VR として扱います — たとえば 3840x1920 や 8192x4096
です。互換性のある VR メタデータや既知の VR スタジオ名によって VR 処理が
有効になる場合もあります。

## VR 投影の選択

モザイクの作り方はスタジオごとに異なるため、すべての動画に合う単一の
設定はありません。Jasna は復元の前に、各モザイク領域を平らにする最適な
方法をスタジオごとに選びます。モザイク以外の部分は一切変更されません。

- **raw** — 見た目のままの領域を使います（不明なスタジオの安全な既定値）。
- **魚眼** — 魚眼ビューでモザイクが正しく見えるスタジオ向け。
- **グノモニック** — ゆがみのない平面ビュー。

動画が VR180 として認識されると、区間エディターの **VR 投影**メニューが
有効になります。**復元プレビュー**をオンにして、**自動**、**raw**、
**魚眼**、**グノモニック**を切り替えると、現在のフレームや再生映像を
比較できます。このコントロールは **復元プレビュー** の横にあり、ラベルには
**自動** が実際に選ぶ投影が表示されます。**適用** を選ぶとその動画用に
設定が保存され、最終処理でもプレビューと同じ投影が使われます。

## モードの意味

- **自動（推奨）**: 検出とスタジオ別の投影選択を Jasna に任せます。
  まずはこれを使ってください。
- **オフ**: 通常の平面動画として処理します。
- **SBS — 左右別処理**: 自動でファイルが認識されない場合に、同じ
  スタジオ別の投影選択でサイドバイサイド VR 処理を強制します。
- **SBS + 魚眼**: スタジオに関係なく、すべてのモザイク領域に魚眼投影を
  強制します。

CLI での指定:

```bash
jasna --input input.mp4 --output output.mp4 --vr-mode auto
jasna --input input.mp4 --output output.mp4 --vr-mode sbs-fisheye
```

# VR180 動画

VR180 ファイルでは、左目と右目の映像が 1 枚のフレームに入っています。通常は
左右に並び（サイドバイサイド、SBS）、上下に重なる場合（トップボトム、TB）も
あります。Jasna はフレームを分割し、左右の目を別々に復元してから、元に
戻します。BasicVSR++ でも LTX でも使えます。

## かんたん設定

1. 他の動画と同じように VR 動画を追加します。
2. **VR180 モード**は**自動（推奨）**のままにします。
3. 同梱の **rfdetr-vr-v1** 検出モデルを使います。**zelefans-vr-yolo-v2**
   （別途ダウンロード）も使えます。
4. 処理を開始します。[区間エディター](segments.md)で一部だけを復元することも
   できます。

自動では、高さが 1080 ピクセルを超える 2:1 の動画をすべてサイドバイサイド
VR として扱います。たとえば 3840x1920 や 8192x4096 です。幅が 1080 ピクセルを
超える 1:2 の動画（たとえば 1920x3840）はトップボトム VR として扱います。
ファイル内の VR メタデータや既知の VR ファイル名でも VR がオンになります。

## 投影

モザイクの作り方は動画の制作元ごとに違うため、1 つの設定ですべての動画には
合いません。Jasna はファイル名から、復元の前にモザイクを平らにする方法を
選びます。それ以外の部分は変更されません。

- **元のまま**: モザイクをそのまま使います。不明なファイル名のデフォルト値です。
- **魚眼**: 魚眼ビューでモザイクが正しく見える動画向けです。
- **ノモニック**: ゆがみのない平面ビューです。

VR180 動画では、区間エディターの**復元プレビュー**の横に **VR投影**メニューが
表示されます。**復元プレビュー**をオンにして、**自動**、**元のまま**、
**魚眼**、**ノモニック**を試してください。ラベルには**自動**が選んだものが
表示されます。**適用**で選択が保存され、最終処理でも使われます。

## モード

- **自動（推奨）**: VR かどうかを Jasna が判断し、ファイル名に合った投影を
  選びます。まずはこれを使ってください。
- **オフ**: 通常の平面動画として扱います。
- **SBS — 左右別処理**: 自動でファイルが認識されないときに、VR 処理を
  強制します。投影はファイル名から選ばれます。
- **SBS + 魚眼**: VR 処理を強制し、すべてのモザイクに魚眼を使います。
- **TB — 上下**: 左目が上にあるファイルで VR 処理を強制します。投影は
  ファイル名から選ばれます。

CLI:

```bash
jasna --input input.mp4 --output output.mp4 --vr-mode auto
jasna --input input.mp4 --output output.mp4 --vr-mode sbs-fisheye
jasna --input input.mp4 --output output.mp4 --vr-mode tb
```

# 動画の一部だけを復元する

動画全体を復元する必要はありません。モザイクのあるシーンだけを選べます。
残りはそのままコピーされるので、処理はずっと速くなり、他の部分は元の品質の
ままです。出力はフル尺の動画のままです。

## 区間エディター（GUI）

<img width="822" alt="Segment editor" src="https://github.com/user-attachments/assets/c67939a9-37de-46ae-b722-20c6a0933df7" />

キュー内の動画のはさみボタンから開きます。

- 復元する区間をフレーム単位で選びます。区間がなければ動画全体を復元します。
- **復元方法**で区間ごとのモデルを決めます: BasicVSR++ または
  [LTX](models.md#復元モデル)。
- **復元プレビュー**は、処理を始める前に復元後の映像を表示します。
  - BasicVSR++ の区間はすぐに表示されます。
  - LTX の区間は先にレンダリングが必要です。**LTX シード N をレンダリング**を押します。
    ボタンにはかかる時間（数分のことが多い）が表示されます。長い処理の前には
    確認されます。
  - LTX のシードを比べるには、別のシードを選んでもう一度レンダリングします。試した
    シードは**試したシード**に並びます。クリックすると表示され、
    **このシードを使う**で決定します。
- **− / +** またはマウスホイールで拡大し、映像をドラッグして移動できます。
  **表示をリセット**で元に戻ります。
- 区間を選ぶと、出力は元動画のコーデックのままです。区間の間の部分は
  コピーされるため、**エンコード**の**コーデック**設定は使われません。
  一部だけを処理できない動画の場合は、エディターがすぐに知らせます。
- BasicVSR++ の区間と LTX の区間の間には、少し間隔が必要です。近すぎる場合は
  エディターが知らせます。

### モザイクスキャン

エディターはモザイクのあるシーンを自動で探せます。

1. 検出モデルと確認の間隔を選びます: 全フレーム（最も正確）または
   0.25～2 秒ごと（速い）。RTX 5090 ではスキャンは約 **2,000 FPS** です。
2. **動画をスキャン**を押します。見つかった区間はタイムラインに琥珀色で
   表示されます。
3. **検出しきい値**スライダーを動かして、見つかったとみなす基準を変えます。
4. **全区間を追加**で、琥珀色の区間が紫色の区間になり、復元対象になります。

- **プレビューにマスクを表示**: 見つかったモザイクを赤で描き、大きさ
  （最も長い辺が動画の高さの何 % か）を表示します。
- **大きなモザイクだけ LTX**: お使いの PC で LTX が使える場合、スキャン後に
  表示されます。モザイクが大きい部分を LTX の区間、それ以外を BasicVSR++ の
  区間にするので、遅い LTX は効果の大きい部分だけで動きます。「大きい」とは、
  最も長い辺が動画の高さに対してスライダーの値 % 以上であることです。
  12% から始めるのがおすすめです。区間を確認し、気に入らないものは変更して
  ください。

検出モデルと検出しきい値はこの動画用に保存され、最終処理でも使われます。他の動画は
それぞれの設定のままです。

### より良いマスクを提案する

検出が間違っている場合は、より良いモデルの訓練に協力できます。そのフレームで
一時停止し、**より良いマスクを提案**を押して、各モザイクの周りを描いて
ください。描き方はエディターが案内します。モザイクの縁がぼやけている場合は、
その部分も含めてください。

Jasna はフレームとマスクを**匿名**でアップロードします。データはアップロード
前にお使いの PC で暗号化されます。一緒に送られるのは、アプリのバージョン、
検出モデル名、フレームサイズだけです。ファイル名や時刻など、あなたに関する
情報は送られません。

## CLI: `--segments`

エディターと同じことをコマンドラインで行います。時刻は秒または
`HH:MM:SS.s` で指定します:

```bash
jasna --input input.mp4 --output output.mp4 --segments "10-25,01:10-01:30.5"
```

Jasna は指定した区間を復元し、残りをコピーします。動画は特定のフレームでしか
切れないため、各区間の前後数秒は再エンコードされます（復元はされません）。

制限:

- NVIDIA と AMD で使えます。
- 一度に 1 本の動画だけです。フォルダー、画像、ストリーミングは使えません。
- 入力: 固定フレームレートの H.264、HEVC、AV1。出力: MP4、MOV、MKV。
- 出力コーデックは常に入力コーデックと同じです。
- AMD では、一部の H.264 ファイルは全体を再エンコードします。復元するのは
  区間だけです。
- `--restoration-model-name ltx` を指定すると、すべての区間が LTX を使います。
- `--retarget-high-fps` や `--fmp4` とは併用できません。

入力が使えない場合、Jasna は処理を始める前にエラーで止まります。

## CLI: `--ltx-auto-split`

**大きなモザイクだけ LTX** のコマンドライン版です。Jasna は各動画を先に
スキャンし、大きなモザイクを LTX、それ以外を BasicVSR++ で復元します。
フォルダーにも使えます:

```bash
jasna --input videos/ --output restored/ --restoration-model-name ltx --ltx-auto-split 12
```

数値はモザイクの大きさで、動画の高さに対する % です。出力は元動画の
コーデックのままです。一部だけを処理できない動画は、全体を LTX で復元します。
`--segments` や `--fmp4` とは併用できません。

## 作業ディレクトリ

動画を組み立てる間、Jasna は出力の隣の隠しフォルダーに一時ファイルを
置きます。別のディスク（より速い、またはより大きい）を使うには、
**エンコード**セクションで**作業ディレクトリ**を設定するか、次のように
指定します:

```bash
jasna --input input.mp4 --output output.mp4 --segments "10-25" --working-directory /fast/scratch
```

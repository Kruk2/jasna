# 高度な処理

特別な場面のための追加機能です。ここにあるものはすべて GUI（各設定に
ツールチップがあります）と CLI の両方で使えます。

## ノイズ除去

復元した部分にはノイズが残ることがあります。**ノイズ除去強度**
（`--denoise low|medium|high`）は、復元した部分だけをきれいにします。
フレームの他の部分は変わりません。まず `low` から始め、ノイズがまだ見える
場合だけ上げてください。

デフォルトでは二次復元の前に実行されます。
`--denoise-step after_secondary` を指定すると最後に移り、復元した部分が
フレームに戻る直前に実行されます。

LTX では使われません。

## 検出の安定化

検出はフレームごとに完璧ではありません。モザイクが 1～2 フレームだけ消える
ことがあります。するとクリップが分かれ、つなぎ目が見えたり、1 フレームが
復元されずに残ったりします。1 フレームだけの誤検出は、必要のない復元を
始めてしまいます。

- **最大検出ギャップ**（`--max-detection-gap`、デフォルト `2`）: モザイクが同じ
  場所に戻ってきた場合、最大 N フレームの途切れを埋めます。
- **最短検出フレーム数**（`--min-detection-duration`、デフォルト `2`）: N フレーム
  より短い検出を捨てます。そのフレームはそのまま残ります。

本当に短いモザイクに影響しないよう、どちらも小さい値にしてください。`0` で
それぞれオフになります。

## シーンカット検出

これがないと、ハードカットをまたいでモザイクが追跡され、復元時に 2 つの別の
ショットが混ざることがあります。**シーンカット検出**（`--scene-detection`、
デフォルトでオン）はハードカットを見つけ、そこですべてのクリップを終えます。GPU で
動き、負担はほとんどありません。

実際にはカットがないのにクリップが分かれる場合だけ、オフにしてください
（`--no-scene-detection`、または**詳細設定**のスイッチ）。

## 60 FPS から 30 FPS へ

60（または 59.94）FPS の動画では、**60 FPS を 30 FPS に変換**
（`--retarget-high-fps`）が 1 フレームおきに処理し、30（または 29.97）FPS で
保存します。処理は半分になります。音声と再生速度は正しいままです。他の
フレームレートは変わりません。

```bash
jasna --input input.mp4 --output output.mp4 --retarget-high-fps
```

[選択した区間](segments.md)やストリーミングとは併用できません。

## 処理中でも再生可能（fMP4）

通常の MP4 は処理が終わるまで開けません。**処理中でも再生可能**（`--fmp4`）
を使うと、作成中の出力を再生できます。たとえば品質を早めに確認できます。
処理が途中で止まっても、ファイルは再生できます。

```bash
jasna --input input.mp4 --output output.mp4 --fmp4
```

映像は数秒ずつ増えていき、処理が終わるまでプレーヤーが正しくない長さを
表示することがあります。`.mp4` と `.mov` の出力だけで使えます。
ストリーミングと[選択した区間](segments.md)では使えません。

## カラー LUT

`.cube` カラー LUT（1D または 3D）を出力に適用して、色を調整できます。
**エンコード**セクションの**カラー LUT (.cube)** で設定するか、
`--lut path/to/look.cube` を使います。動画の書き出し時に適用されるので、
負担はほとんどありません。

## シャープネス

復元した映像は少し柔らかく見えることがあります。**エンコード**セクションの
**シャープネス**（`--sharpen`）は、保存しながら輪郭や細部をくっきりさせます。
別のツールは不要です。

```bash
jasna --input in.mp4 --output out.mkv --sharpen 0.5
```

`0` はオフ、`0.2`〜`0.5` は控えめな効果、`1` は最も強く、硬すぎて見える
ことがあります。シャープな映像にはより多くのビットが必要です。結果が悪く
見える場合は、CQ も下げてください。プレビューにはシャープネスは表示されません。

## エンコーダー品質とカスタム設定

**CQ**（`--cq`）は品質を決めます。低いほど高品質で、ファイルは大きくなります。
Jasna は出力サイズにも上限を設けていて、上限に達すると近い CQ 値で同じ
ファイルになることがあります。

```bash
jasna --input in.mp4 --output out.mkv --cq 22
```

**カスタム引数**（`--encoder-settings`）は、ビットレート上限やキーフレーム
間隔など、その他のエンコーダー設定に使います。GUI ではここで CQ は設定
できません。CQ コントロールを使ってください。すべてのキー、範囲、デフォルト値は
[CLI リファレンス](cli.md#エンコード)にあります。

## キューの完了後

キュー全体が終わったときに何かを実行できます: **PC をシャットダウン**、
または**カスタムコマンド**（たとえばメッセージを送るスクリプト）です。
**エクスポート後のアクション**セクションか、CLI で設定します:

```bash
jasna --input input.mp4 --output output.mkv --post-export-action shutdown
jasna --input folder_in --output folder_out --post-export-action command --post-export-command "echo done"
```

ジョブの実行中でも、このアクションを変更したりオフにしたりできます。
**PC をシャットダウン**の前に、GUI は 60 秒のカウントダウンを表示します。
PC をつけたままにするには**キャンセル**を押します。CLI ではすぐにシャットダウンします。

完了した動画ごとにコマンドを実行するには、**動画ごとのコマンド**または
`--post-export-video-command` を使います。Jasna はコマンドが終わるまで
待ちます。コマンドが失敗すると、その動画は失敗として扱われます。コマンドは
出力フォルダーで実行されます。

プレースホルダー: `{input}`、`{output}`、`{output_dir}`、`{output_stem}`、
`{output_suffix}`。引用符はすでに付いています。例は
[CLI リファレンス](cli.md#エクスポート後)にあります。

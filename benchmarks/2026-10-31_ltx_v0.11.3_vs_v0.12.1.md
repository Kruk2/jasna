# LTX: v0.11.3 vs v0.12.1 release builds (2026-10-31)

RTX 5090 (driver 595.104.02), official Linux NVIDIA release builds run from the CLI: v0.11.3 (tag `cf8a968c`) and
v0.12.1 (main `26f42221`). One 45 s 1080p60 video (2698 frames, about 31 windows), default settings of each
version (HEVC, NVIDIA defaults), INT8 models, output on a local SSD. Wall time is the whole job as the user sees
it, measured outside the program, including startup and model loading. Each build/model/canvas had one discarded
first run; timed values are averages of the following runs (two for v0.11.3, three for v0.12.1 Standard, two for
Basic, one for each large-canvas row). Run-to-run spread was up to about 10 %. Per-run values in the `.csv`.

| Run | Wall time |
|---|---|
| 0.12.1, 2-step | 95.2 s (-30 %) |
| 0.11.3, 2-step | 135.3 s |
| 0.12.1, 1-step | 79.6 s (-41 % vs 0.11.3 2-step) |
| 0.12.1, 2-step, large canvas | 169.1 s (-21 %) |
| 0.11.3, 2-step, large canvas | 213.5 s |
| 0.12.1, 1-step, large canvas | 114.3 s (-46 % vs 0.11.3 2-step) |

2-step is Standard Quality, 1-step is Basic Quality (new in 0.12.1), large canvas is "Sharper large mosaics"
(here 20 of the 31-32 windows ran at 768).

## Per window, from the in-job `[timing]` lines

Seconds per 121-frame window (denoise per step), averaged over the timed runs:

| | Encode 512 | Decode 512 | Denoise 512 | Encode 768 | Decode 768 | Denoise 768 |
|---|---|---|---|---|---|---|
| 0.11.3, 2-step | 0.44 | 0.90 | 0.49 | 0.94 | 2.00 | 1.35 |
| 0.12.1, 2-step | 0.28 | 0.37 | 0.60 | 0.58 | 0.78 | 1.33 |
| 0.12.1, 1-step | 0.30 | 0.39 | 0.76 (one step) | 0.57 | 0.78 | |

The VAE encoder and decoder do most of the gain: compose (decode and blending) fell from 33-44 s to 14-18 s per
job at 512. In 0.12.1 the stages overlap more on the GPU, so the in-job denoise time per step reads higher than in
0.11.3 and the stage times no longer add up to the job time; compare the wall times, not the stages. Standalone
per-window VAE numbers are in `2026-10-28_ltx_vae_choices.md`.

## Other notes

- First runs are slower: they compile GPU kernels and, the first time a model is used, run the LTX speed test.
  First runs took 285 s (0.11.3, 2-step), 127 s (0.12.1, 1-step), and at the large canvas 270 s (0.11.3) and
  199 s (0.12.1).
- LTX peak VRAM is about the same: 15.1 GB (0.11.3) vs 15.4 GB (0.12.1) at 512, 17.6 vs 17.7 GB with the large
  canvas.
- The two versions found slightly different mosaic tracks on this video (32 vs 31 windows at 512, 64 vs 62
  window-steps), which accounts for about 3 % of the difference.

Not measured: Fast mode (NVFP4), other GPUs, AMD, longer videos.

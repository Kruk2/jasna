# LTX on a Radeon AI PRO R9700: v0.12.3 against main (2026-11-21)

Standard LTX (`ltx`, 2-step distilled INT8), full VAE encoder and decoder, 512 canvas, HEVC output, on a
Radeon AI PRO R9700 (gfx1201, 32 GB). v0.12.3 (`f652800a`) against main `b91a751d`, both from source trees with
the same plaintext weights. Raw rows: `2026-11-21_amd_r9700_ltx_0.12.3_vs_main.csv`.

S610, 1080p H.264, 6056 frames, 144 windows. One run per row. Before its cold run each tree ran a 10 s job, so
its native block, kernels and Triton caches were built. Then its MIOpen user cache was emptied (cold), and the
warm run reused that cache. Both trees ran the LTX transformer on the native block, which is the path releases
use. LTX stage seconds:

| run | v0.12.3 | main |
|---|---|---|
| cold | 1238.6 | 1169.7 (-5.6 %) |
| warm | 1016.1 | 1011.1 (-0.5 %) |

| pass | v0.12.3 cold | main cold | v0.12.3 warm | main warm |
|---|---|---|---|---|
| scan | 49.1 s | 47.7 s | 47.6 s | 50.6 s |
| encode | 241.2 s | 238.6 s | 162.5 s | 161.5 s |
| denoise | 575.4 s | 560.2 s | 588.8 s | 533.5 s |
| compose | 372.9 s | 323.2 s | 217.2 s | 265.6 s |
| decode per window | 1.31 s | 1.34 s | 1.31 s | 1.33 s |

- Per-window encode (0.99 s), per-step denoise (1.43 s) and per-window decode (1.31-1.34 s) match between the
  trees. The totals differ in the work around them, and one run per row does not separate that from noise.
- Compose: main is 50 s faster cold and 48 s slower warm. Both cold runs pay MIOpen searches, and v0.12.3's
  warm compose reuses this clip's shapes. With one run each, neither difference is settled.
- Wall time adds model loading and process exit. On this pod each LTX process took about 4-5 minutes to exit
  (memory pages being written back on a 15 GB RAM host), so wall time says little about speed here.
- All four outputs have 6056 frames. No GPU fault event (`amd-smi event`) during the runs.

## Setup

Rented pod: privileged Docker, Ubuntu 26.04, one Radeon AI PRO R9700 (gfx1201, 32 GB, 256 MB CPU-visible VRAM),
Intel Core i3-8100 (4 cores), 15 GB RAM, amdgpu 7.1.9, ROCm 10.1 userspace, AMF 26.20. Python 3.12,
torch 2.14.0+rocm10.1.0, `rocm-sdk-devel` 10.1.0. All 48 transformer blocks resident.

# Windows: v0.12.2 vs v0.12.3 release builds (2026-11-09)

RTX 5090 (driver 610.74), Windows 11, both builds on the local SSD. v0.12.2 is the official archive (tag `v0.12.2`,
`12510264`); v0.12.3 is a release build of main `307f8083` from a clean checkout. One 15 s 1080p30 clip (449
frames), CLI defaults plus the canonical benchmark settings (`scripts/benchmark_releases.py`: clip size 180,
overlap 15, no secondary restoration), HEVC output. Wall time is the whole job as the user sees it, measured
outside the program. Each build had one discarded first run per mode; the job times are medians of three runs,
alternating the two builds. Per-run values in the `.csv`.

| Run | v0.12.2 | v0.12.3 |
|---|---|---|
| BasicVSR++ | 20.0 s | 21.2 s (+1.2 s, +6 %) |
| LTX Standard (2 steps) | 99.2 s | 106.4 s (+7.2 s, +7 %) |

## Where the time goes

Separate runs with timestamps (three per build for BasicVSR++, one per build for LTX):

| Phase (BasicVSR++, median) | v0.12.2 | v0.12.3 |
|---|---|---|
| Start until "installation verified" | 6.6 s | 7.0 s |
| Then until the first log line (app start, detector load) | 6.2 s | 7.5 s |
| Then until exit (the actual restoration) | 7.3 s | 7.4 s |

The restoration itself runs at the same speed; v0.12.3 starts about 1.5 s slower. For LTX the per-window rates are
the same in both builds (encode 0.46-0.48 s per window, denoise 0.48-0.49 s per window-step, decode 0.76-0.77 s per
window at 512); the LTX pass took 84.1/85.8 s (v0.12.2) and 86.3/88.7 s (v0.12.3) in two pairs of runs. So about
2-3 s of the difference is a fixed cost around the LTX pass and about 1.5 s is the slower start; the timed pair
differed by 3.6 s in total, the medians by 7.2 s, so the rest is run-to-run spread. Since the per-frame and
per-window rates did not change, longer videos should see the same few seconds per job, not a percentage.

## Other notes

- The v0.12.3 LTX output matches v0.12.2: PSNR between the two outputs is 54.1 dB (minimum 50.2 dB per frame), against
  43.5 dB between the input and the v0.12.2 output.
- First runs: BasicVSR++ 211.8 s (v0.12.2) and 184.9 s (v0.12.3), building the TensorRT detector engine; LTX
  477.4 s and 497.6 s, compiling GPU kernels and running the LTX speed test.
- Peak RAM about the same (3.7-3.9 GB). VRAM was not sampled.

Not measured: longer videos, Fast mode (NVFP4), other GPUs, AMD.

# Included license texts

- `Apache-2.0.txt`: VALI, RF-DETR, OpenMMLab MMagic, and other Apache-2.0 components.
- `BSD-3-Clause.txt`: PyAV.
- `GPL-3.0.txt`: the GPLv3 FFmpeg libraries and command-line tools.
- `LTX-2.x-Community-License.txt`: Lightricks LTX-2.5 code ported into
  `jasna/ltx/` and `jasna/models/ltx_vae/`, and the LTX restoration model weights.
- `LGPL-2.1.txt`: libVLC and python-vlc under LGPL-2.1-or-later.
- `LGPL-3.0.txt`: FFmpeg library code under LGPL-3.0-or-later.
- `Python-3.13.txt`: CPython 3.13.

Jasna's AGPL-3.0 license is the repository and release-root `LICENSE` file.
Official binary builds also collect license files from the installed Python
distributions into `licenses/python-packages/`.
